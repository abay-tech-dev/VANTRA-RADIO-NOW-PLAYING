Set up Last.fm once (free, ~5 min):
  1. Create an account on last.fm.
  2. Spotify: last.fm › Settings › Applications › Spotify Scrobbling › Connect.
    Play a song: your Last.fm profile must show Scrobbling now.
  3. Get an API key at last.fm/api/account/create (any app name, leave the URLs empty). Copy the API key, not the shared secret.
  4. Play a song, type your username and key above, click Test my Last.fm.
